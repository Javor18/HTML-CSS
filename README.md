# HTML and CSS Practice

Learning exercises in document structure, typography, the box model, Flexbox, layout and responsive design.

This is a learning archive. The independent exercises record practice and coursework; they do not form one production application. Some exercises expect interactive input or their own supporting files.

## Using the archive

Choose an exercise in its laboratory, exercise or exam folder and read its source before running it. Python exercises use Python 3; frontend exercises may require a browser. There is no single application entry point or claimed comprehensive test suite.

## Portfolio organization

The archive is retained as background for the author's later cybersecurity and automation projects. Generated environments, caches and editor metadata are excluded from the proposed cleanup. Original lesson structure and exercise source files are preserved.
